## 📌 Project Overview

This project explores airline passenger feedback and service-quality data to understand **what drives passenger satisfaction, where service gaps occur, and how operational factors affect the customer experience**.

The dashboard converts raw passenger data into interactive KPIs, trends, comparisons, and analytical visuals that make the data easier to understand and use for decision-making.

## 🎯 Objectives

- Analyze overall passenger satisfaction.
- Identify the strongest and weakest service areas.
- Examine the impact of flight delays and operational issues.
- Compare satisfaction across passenger and travel categories.
- Build an interactive dashboard for quick business analysis.
- Present actionable insights through clear visual storytelling.

## 📊 Dashboard Highlights

### KPI Analysis

- Total passenger responses

### Interactive Analysis

- Passenger satisfaction trends

- Customer feedback patterns
- Drill-down and slicer-based exploration

## 🧩 Data Model

The project uses a structured Power BI data model designed for analytical reporting.

**Core components include:**

- Fact table for passenger/service responses
- Dimension tables for categories and dates
- Relationships supporting interactive filtering
- DAX measures for KPIs and calculated insights
